# 0046: 鎖状部分はジグザグ配置（結合角を交互に反転）を使用する

- Date: 2026-09-03
- Status: Accepted
- Category: architecture
- Deciders: the user, Claude Code

## Context

[[0045]]で2Dレイアウトを独立した関数として実装することを決めた後、鎖状部分（環に属さない直鎖・分岐）の具体的な配置方式を検討した。[[0019]]は固定結合角（120度など）で伸ばすことのみを定めており、その角度を毎回同じ向きに使うか、交互に反転させるかは未定だった。

## Decision

鎖状部分はジグザグ配置を採用する。1つ前の結合の方向を記憶し、次の結合はその反対側に固定角度（120度想定）で振る。これにより、化学の教科書・骨格式で見慣れたジグザグの見た目になる。

## Alternatives

- 一直線配置（すべての原子を同じ方向に並べる）: 実装が最も単純という利点があったが、骨格式の標準的な見た目とかけ離れており「構造式描画ツール」としての説得力に欠けること、分岐がある場合に分岐先の結合角も不自然に見えやすいことから不採用。

## Consequences

- 実装時、直前の結合方向を状態として保持し、次の結合方向を決める際に反転させるロジックが必要になる（一直線配置より若干複雑だが許容範囲）。
- 分岐点での角度分配（1つの原子から3本以上の結合が出る場合の各方向の決め方）は本AnyDRのスコープ外で、別途検討する。
