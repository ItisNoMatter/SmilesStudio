# 0047: 分岐点は対称的なY字分岐（出ていく結合を±120度で対称配置）とする

- Date: 2026-09-03
- Status: Accepted
- Category: architecture
- Deciders: the user, Claude Code

## Context

[[0046]]で鎖状部分のジグザグ配置を決めた後、1つの原子から3本以上の結合が出る分岐点（例: 酢酸`CC(=O)O`の中央炭素）での角度配分を検討した。`Molecule`のドメインモデルには、どの結合がSMILES構文上の「本線の継続」でどれが「括弧内の分岐」かを区別する情報（`Bond`への由来フラグ等）が存在しないことを確認した。

## Decision

分岐点は対称的なY字分岐とする。入ってきた結合の逆方向（直進方向）を基準に、出ていく結合を±120度で対称配置する。鎖状部分の出ていく結合が1本の場合はAnyDR 0046のジグザグ（片側に振る）、分岐点で2本の場合はY字（両側に振る）という同一ロジックの延長として扱う。

## Alternatives

- 本線は直進し分岐だけ角度をつけて逸らす方式: より本格的な骨格式の見た目になり、長い鎖でも本線が一貫したジグザグとして読めるという利点があったが、「どの結合が本線の継続で、どれが分岐か」を区別する情報が現状の`Molecule`ドメインモデルに存在せず、区別のために`SmilesParser`から`Molecule`/`Bond`まで手を入れるか、グラフ構造から最長パスを推定するヒューリスティックが必要になり、[[0019]]が明示的に避けた複雑さ（力学モデル等の不採用）に逆行するため不採用。

## Consequences

- `Bond`にSMILES構文上の由来を示す情報を追加する必要がなく、ドメインモデルは変更不要。`Molecule.bonds`の並び順（既存のリストの出現順）をそのまま使って出ていく結合を振り分けられる。
- 長い鎖の途中に分岐がある場合、「本線」の見た目が分岐のたびに折れ曲がりうる。v1スコープ（[[0018]]の「単純な分岐」）では問題にならない想定。より本格的な骨格式表現が必要になった場合は本AnyDRを再訪する。
