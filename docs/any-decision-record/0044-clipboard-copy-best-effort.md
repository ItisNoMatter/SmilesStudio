# 0044: ツイート作成Skillはドラフトをクリップボードにベストエフォートでコピーする

- Date: 2026-09-03
- Status: Accepted
- Category: process
- Deciders: the user, Claude Code

## Context

[[0039]]〜[[0043]]でBuildInPublicツイート作成Skillの主要な設計（配置場所・英語版AnyDRの格納場所・呼び出し方・言語・ハッシュタグ/トーン）を確定した後、実際にツイートを投稿するのはユーザー自身である（この環境にはX/Twitter投稿用のツールがなく、Skillの役割はドラフト作成に限られる、[[0039]]の前提）ことを踏まえ、ドラフトしたツイート文をユーザーが貼り付けやすくする工夫を検討した。

## Decision

ツイート作成Skillは、ドラフトしたツイート文をチャット上に出力するとともに、ベストエフォートでOSのクリップボードにもコピーする。クリップボードアクセスができない環境（対応するコマンドがない、権限がない等）では、コピーに失敗してもエラーにはせず、チャット出力のみにフォールバックする。

## Alternatives

- チャット出力のみ（クリップボードコピーなし）: 常にどの環境でも確実に動作するという利点があったが、ユーザーが手動でコピーする一手間が発生するため、「親切なスキル」という観点でクリップボードコピーを追加することにした（Aは廃案というより、フォールバック先として引き続き有効）。

## Consequences

- 実装時、OS判定（Windows/macOS/Linux）を行い、それぞれ適切なクリップボードコマンド（例: Windowsは`clip`、macOSは`pbcopy`、Linuxは`xclip`/`wl-copy`等）を試す必要がある。
- コピーの成否に関わらず、チャット出力は必ず行う（クリップボードコピーはあくまで追加の利便性であり、唯一の出力手段にはしない）。
