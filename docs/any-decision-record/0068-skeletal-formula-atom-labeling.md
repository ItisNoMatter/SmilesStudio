# 0068: 原子ラベルは骨格式方式（炭素はラベルなし）で表示する

- Date: 2026-09-04
- Status: Accepted
- Category: architecture
- Deciders: the user, Claude Code

## Context

[AnyDR 0067](./0067-drawing-plan-as-pure-function.md)で描画計画を純粋関数として切り出す方針を決めた後、原子のラベル表示方針（どの原子にどんなテキストを表示するか）を決める必要があった。`Atom`は`element: Element`を1つ持ち、水素は別Atomとしてではなく`hydrogenCount`という付随プロパティとしてのみ表現される（暗黙の水素は元々頂点として描画されない）ため、論点は炭素以外の重原子の元素記号をどう表示するかに絞られた。

## Decision

原子ラベルは骨格式（Skeletal Formula）方式で表示する。炭素原子はラベル（テキスト）を描画せず、線の交点・端点として暗黙的に表現する。炭素以外の元素（N、O等）のみ元素記号をラベル表示する。

## Alternatives

- 全原子にラベル表示（炭素も含む）: 実装がシンプルで例外処理が不要、化学に不慣れなユーザーにも常に原子種が明示されるという利点があったが、実際の骨格式の慣習とは異なり炭素の多い分子で見た目が煩雑になるため不採用。CLAUDE.mdが「化学徒向け」ツールと明言しており、標準的な骨格式表現の方がターゲットユーザーに自然と判断した。

## Consequences

- 描画計画（AnyDR 0067）を計算する純粋関数は、炭素かどうかで原子ラベルの有無を分岐するロジックを持つ必要がある。
- ラベルなしの炭素頂点も、結合線が交わる/終端する位置として視覚的に認識できる必要がある（明示的な点や円の描画は必須ではなく、結合線自体で表現される想定）。
