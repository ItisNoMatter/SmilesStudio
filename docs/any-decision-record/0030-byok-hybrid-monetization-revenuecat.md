# 0030: RevenueCatによるBYOKハイブリッド課金モデルを採用する

- Date: 2026-09-02
- Status: Accepted
- Category: architecture
- Deciders: the user

## Context

Shipaton 2026（[[0027]]）はRevenueCat SDK導入とアプリ内課金/Web課金の実装を参加要件としている。Koogはクライアント構築時にAPIキーを渡す設計（例: `OpenAILLMClient(apiKey)`）のため、ユーザー自身のAPIキーをそのまま利用する実装（BYOK）が技術的に可能であり、これを課金モデルの土台として使えることが分かった。ダークパターン（意図的なラグ＋広告表示によるコンバージョン誘導）は方針として不採用と決定済み。

## Decision

BYOKハイブリッドモデルを採用する。無料プランはユーザーが自分のLLM APIキーを設定すれば[[0028]]の手描き画像→SMILES変換機能を無制限に利用できる。有料プランはAPIキーの取得・管理が不要で、アプリ側が提供する枠内でAI変換機能を利用できる（利便性を売る）。有料プランには1週間の無料トライアル（全機能使い放題、キー設定不要）を設定し、RevenueCat SDKでトライアル→サブスク移行を実装する。設定画面には「自分のAPIキーを使う」か「アプリのAI機能を購読する」かを選べる導線を用意する。

## Alternatives

- ダークパターン型の課金導線（意図的なラグ・強制広告表示によるコンバージョン誘導）: モデル自体の是非とは独立に、方針として明示的に不採用とした。

## Consequences

- 開発者が常に推論コストを負担する必要はなく、無料プラン利用者は自分のキーでコストを負担するため、開発者が見積もるべきコストは有料プラン利用者分のみに限定される。
- 有料プラン（アプリ側APIキーを全ユーザーでプール）について、現時点ではユーザーごとの使用上限（レート制限等）は決めていない。ハッカソンの短い期間・小規模な想定ユーザー数を踏まえ、MVPとしてこのコスト超過リスクを意図的に受け入れる（本セッションでユーザーに確認済み）。アプリがハッカソン後も継続する場合は、利用上限・レート制限の導入を再検討する必要がある。
- 価格帯（月額300〜500円、年額2,000〜3,000円程度）はあくまで参考値であり、本AnyDRで確定させるのはBYOKハイブリッド＋トライアルという「モデル」自体のみ。具体的な価格は別途検討中（未確定）。
