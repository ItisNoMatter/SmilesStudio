# 0006: v1ロードマップをグリリングで確定しGitHub Issue化

- Date: 2026-09-01
- Related AnyDR: 0017, 0018, 0019, 0020, 0021, 0022, 0023
- Related Issue: #1〜#10

## Objective

「プロジェクト全体の進め方の構想を整理してissue化したい。最小構成でユーザーにリリースできる
ところまで」という目標に向けて、v1のスコープと配布方式を確定し、GitHub Issueに落とし込む。

## Action

`/grill-with-docs`で連続する論点を順に決定した: コア体験をテキスト編集+読み取り専用描画に
限定（0017）、SMILES文法スコープに環閉包・芳香族小文字表記を含める（0018）、2Dレイアウトは
固定角度配置を自前実装（0019）、芳香族結合はKekulé構造で描画（0020）、配布はjpackageベースの
ネイティブインストーラをGitHub ReleasesでWindows向けのみ配布（0021）、Issue構成はWayfinder
方式を採用（0022）、配布物作成はGitHub Actionsで自動化（0023）。決定を踏まえ、Wayfinderマップ
（Issue #1）と子Issue群（#2〜#10）を作成した。

## Result

v1の全体設計が確定し、GitHub Issue #1〜#10としてバックログ化された。以降の実装作業はこの
ロードマップに沿って進む。

## Reflections

「エディタ」という言葉一つが「テキスト編集」なのか「グラフィカルな直接編集」なのか曖昧だった
ことが、コア体験を最初に確定させる出発点になった。曖昧な言葉を早期に精密化することが、その後
の一連の決定（文法スコープ・レイアウト・配布形態）の前提を安定させた。
