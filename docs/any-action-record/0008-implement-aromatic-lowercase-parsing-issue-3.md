# 0008: SMILES芳香族小文字表記パース（Issue #3）をTDDで実装

- Date: 2026-09-01〜2026-09-02
- Related AnyDR: 0025
- Related Issue: #3

## Objective

Issue #3（SMILESパーサー: 芳香族小文字表記への対応）を完了させる。

## Action

芳香族小文字表記（`c1ccccc1`等）を`Token.AtomSymbol`にフラグを足す案ではなく別トークン型
`Token.AromaticAtomSymbol`として表現する方針を、型レベルでの強制力を理由に選択した
（AnyDR 0025）。`b`（ホウ素）は`Element`列挙型に未対応のため対象外とし、`c,n,o,p,s`の5元素を
対象にTDDで実装した。

## Result

`c1ccccc1`（ベンゼン）のような芳香族SMILESがパースできるようになった。`147de49`で実装完了、
Issue #3クローズ。

## Reflections

「同じ元素種だが書き方が違うだけ」という実態に忠実な軽量案（フラグ追加）よりも、コンパイラに
新しい分岐の実装漏れを検出させられる型安全な案（別トークン型）を優先した。AI支援開発を前提に
した際、型システムの強制力を実装コストより優先する判断がこのプロジェクトで繰り返し現れている。
