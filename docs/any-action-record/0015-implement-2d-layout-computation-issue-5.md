# 0015: 2Dレイアウト計算（Issue #5）を固定角度アルゴリズムでTDD実装

- Date: 2026-09-03
- Related AnyDR: 0045, 0046, 0047
- Related Issue: #5

## Objective

Issue #5（2Dレイアウト計算）を完了させ、`Molecule`の原子・結合グラフから描画用の2D座標を
計算できるようにする。

## Action

`/grill-with-docs`でレイアウト計算を`Molecule`から独立した関数として実装する方針（0045）、
鎖は±120度のジグザグ配置とする方針（0046）、分岐は入ってきた方向の逆向きを基準にした対称な
Y字フォークとする方針（0047）を確定した。TDDで`Point2D`・`computeLayout()`を実装した。
Kotlinのローカル関数同士が前方参照できない制約に当たり、`lateinit var`の関数型プロパティに
置き換えて相互再帰を実現した。環に結合した置換基が環の中心から外向きではなく環に接する形で
配置されてしまうバグをテストで検出し、環の置換基は±120度オフセットを使わず外向き方向に直接
配置するロジックを追加して修正した。

## Result

直鎖・分岐・環いずれのSMILESについても幾何学的に妥当な2D座標が計算できるようになった。
`899571e`で実装完了、テスト7件グリーン、Issue #5クローズ。

## Reflections

座標の厳密な期待値ではなく、結合長や結合角といった幾何学的な性質をテストで検証する設計に
したことで、レイアウトの細部を変更してもテストが壊れにくい形になった。環の置換基のバグは、
一般的な鎖のオフセット式を環にもそのまま流用してしまったために起きたもので、「似ているが実は
違うケース」をテストで具体的に踏んでみるまで気づけなかった。
